# 聞き流し論証プレイヤー

暗記用テキストの読み上げ音声を連続再生するための、オフライン動作のWebプレイヤー(PWA)です。

- 音声・テキストデータはこのリポジトリには含まれません(利用者がローカルで生成した `.kkpack` ファイルを取り込んで使います)
- 取り込んだデータは端末内(IndexedDB)にのみ保存されます
- バックグラウンド再生・ロック画面操作(Media Session)・シャッフル・速度変更(0.75〜1.5x)対応

## 使い方

1. このページをiPhoneのSafariで開き「ホーム画面に追加」
2. 「ライブラリ」タブから `.kkpack` ファイルを取り込む
3. 「プレイヤー」タブで再生

`.kkpack` の生成は別途ローカルのツール(edge-tts利用)で行います。
